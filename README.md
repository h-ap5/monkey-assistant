# 몽키 어시스턴트 v0.5

Tampermonkey 백업 ZIP과 `.user.js`를 브라우저에서 분석하는 GitHub Pages용 정적 웹앱입니다.

## v0.5 변경 사항

- 상담창을 열면 우측 하단 실행 버튼이 자동으로 숨겨집니다.
- 빠른 질문을 상담창 하단 3열 그리드로 배치해 가로 스크롤을 없앴습니다.
- 첫 인사말을 기본 고양이체로 변경했습니다.
- 복잡했던 여러 API 공급자 설정을 제거했습니다.
- 개인 Gemini API 키만 선택적으로 연결합니다.
- 기본 모델은 `gemini-2.5-flash-lite`입니다.
- API 키가 없거나 Gemini 사용을 끄면 기존 로컬 상담이 작동합니다.

## GitHub Pages 업데이트

이 폴더 안의 파일을 기존 저장소 최상단에 전부 업로드하고 같은 이름 파일을 덮어쓴 뒤 `Commit changes`를 누르세요. 배포 후에는 `Ctrl + Shift + R`로 강력 새로고침하세요.

## API 키

상담창 우측 상단의 톱니바퀴에서 **Gemini AI 상담 사용**을 켜고 Google AI Studio에서 발급받은 개인 키를 입력합니다. 기본적으로 현재 탭에만 보관되며, 사용자가 직접 **이 브라우저에 API 키 기억**을 켠 경우에만 브라우저 저장소에 남습니다.

## 개인정보

ZIP과 유저스크립트 분석은 브라우저 내부에서 처리됩니다. Gemini AI 상담을 켠 경우에는 질문과 정적 분석 요약만 Google Gemini API로 직접 전송하며, 원본 코드 전체는 보내지 않습니다.
