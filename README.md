# 몽키 어시스턴트 v0.3.0

Tampermonkey 백업 ZIP과 `.user.js` 파일을 브라우저 안에서 분석하는 GitHub Pages용 웹사이트입니다.

## v0.3.0 변경 사항

- `JSZip is not defined` 오류 수정
  - JSZip을 `app.bundle.js` 안에 직접 포함했습니다.
  - 이제 `vendor` 폴더나 외부 CDN이 없어도 ZIP을 읽습니다.
- 초록색 포인트 제거
- 대형 홍보 문구와 랜딩 화면 제거
- 기존 크롬 확장프로그램과 비슷한 왼쪽 사이드바형 UI 적용
- 업로드 영역을 작고 직관적으로 변경
- 플로팅 상담 어시스턴트와 말투 설정 유지
- 모바일 화면 대응 개선

## 기존 GitHub 저장소 업데이트 방법

1. 이 폴더 안의 파일을 모두 선택합니다.
2. GitHub 저장소에서 `Add file` → `Upload files`를 누릅니다.
3. 파일들을 드래그해서 업로드합니다.
4. 같은 이름의 파일이 있으면 새 파일로 교체됩니다.
5. `Commit changes`를 누릅니다.
6. 배포 후 사이트에서 `Ctrl + Shift + R`로 강력 새로고침합니다.

중요한 파일은 다음 세 개입니다.

- `index.html`
- `styles.css`
- `app.bundle.js`

`index.html`은 이제 `vendor/jszip.min.js`와 `app.js`를 불러오지 않습니다. ZIP 분석 라이브러리와 앱 코드가 모두 `app.bundle.js` 하나에 들어 있습니다.

## 사용법

1. Tampermonkey 대시보드의 유틸리티 또는 백업 메뉴에서 ZIP 백업을 만듭니다.
2. ZIP을 압축 해제하지 않고 몽키 어시스턴트의 업로드 영역에 놓습니다.
3. 분석 결과를 확인합니다.
4. 우측 하단 `어시스턴트` 버튼을 눌러 중복이나 충돌에 대해 질문합니다.

모든 분석은 현재 브라우저 안에서 처리됩니다. 외부 API를 사용하지 않습니다.
