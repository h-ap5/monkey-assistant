# 🐒 몽키 어시스턴트

템퍼몽키 백업 ZIP이나 유저스크립트를 넣으면, 코드 대신 **“그래서 뭘 남기고 뭘 끄면 되는지”**부터 알려주는 브라우저 도구입니다.

원본 파일을 자동으로 삭제하거나 템퍼몽키 설정을 바꾸지는 않습니다. 판단 근거와 순서를 보여주고, 마지막 정리는 사용자가 직접 하도록 설계했습니다.

## 결과는 네 가지로 읽으면 됩니다

| 표시 | 뜻 | 권장 행동 |
|---|---|---|
| **유지** | 뚜렷한 중복·충돌을 찾지 못함 | 그대로 사용 |
| **업데이트** | 같은 스크립트 계열에서 더 새 버전을 찾음 | 최신본이 정상인지 확인한 뒤 구버전 끄기 |
| **한쪽 끄기** | 같은 페이지의 같은 기능을 동시에 건드릴 가능성이 큼 | 추천본만 켜고 문제가 없는지 시험 |
| **직접 확인** | 이름은 비슷하지만 기능이 다르거나 정적 분석만으로 결론 내리기 어려움 | 근거를 펼쳐 본 뒤 결정 |

각 항목에는 다음 정보가 함께 표시됩니다.

- 지금 할 일과 안전한 확인 순서
- 판단 확신도
- 함께 켰을 때 생길 수 있는 현상: 버튼 가림·겹침, 기능 미작동, 설정 변화, 느려짐 등 코드에서 단서가 확인된 항목만 표시
- `왜 이렇게 판단했는지 보기`를 열면 겹친 사이트·화면 요소·저장 키·통신 처리 등 기술적 근거 표시
- 같은 계열의 구버전인지, 기능이 달라진 별도판인지에 대한 설명

## 지원 기능

- 템퍼몽키 백업 ZIP을 압축 해제 없이 분석
- 개별 `.user.js`, `.js`, `.txt` 파일 여러 개 가져오기 (`==UserScript==` 메타 블록이 있는 파일)
- 완전히 같은 파일 찾기
- 이름·네임스페이스·업데이트 주소·코드 특징을 함께 본 버전 계열 판정
- 버전 번호는 같지만 기능이 다른 변형판·포크 후보 구분
- 적용 사이트와 DOM, 저장소, CSS, 이벤트, 통신 후킹이 겹치는 충돌 후보 탐지
- 검색 및 사이트·상태별 필터
- 근거가 포함된 HTML 보고서 저장
- 원할 때만 분석 결과를 브라우저에 기억하며, 원본 코드는 저장하지 않음
- 선택 기능인 원격 최신 버전 확인과 Gemini 상담
- 밝은 화면·어두운 화면 및 모바일 레이아웃

## 사용법

1. 템퍼몽키의 백업 ZIP 또는 유저스크립트 파일을 화면에 놓습니다.
2. **한눈에 보기**에서 먼저 정리할 항목을 확인합니다.
3. 각 항목의 **지금 할 일**과 **판단 근거**를 읽습니다.
4. 템퍼몽키에서 추천된 한쪽만 먼저 끄고 사이트가 정상인지 시험합니다.
5. 문제가 없을 때만 꺼둔 복사본이나 구버전을 직접 삭제합니다.

처음부터 삭제하기보다 **끄기 → 새로고침 → 기능 시험 → 나중에 삭제** 순서를 권장합니다.

새 백업 ZIP을 다시 넣으면 이전 백업 분석을 새 시점의 목록으로 교체합니다. 개별 파일을 다시 넣을 때는 같은 파일명의 이전 판을 새 판으로 바꿉니다. 그래서 예전 분석에 남은 파일을 현재도 설치된 구버전으로 잘못 세지 않습니다.

## 최신 버전 확인

`최신 버전 확인`은 사용자가 버튼을 눌렀을 때만 실행됩니다. `@updateURL`, `@downloadURL`, 또는 템퍼몽키 백업 설정의 원본 주소(`meta.file_url`)에서 메타데이터를 읽어 버전 번호를 비교하며, 내려받은 코드를 실행하지 않습니다.

- 연결하기 전에 대상 배포 서버의 호스트 목록과 요청 개수를 보여주고 확인을 받습니다.
- 공개 HTTPS 기본 포트만 허용하며, localhost·사설망·로컬 주소와 리디렉션은 차단합니다.
- 주소가 없거나 서버가 브라우저 요청을 허용하지 않으면 확인할 수 없습니다.
- 주소의 스크립트 이름과 네임스페이스가 로컬 파일과 일치해야 합니다. 네임스페이스가 빠진 파일은 이름과 파일 내부의 배포 주소까지 일치할 때만 같은 스크립트로 봅니다.
- 비표준 버전 번호는 `직접 확인`으로 남을 수 있습니다.
- 이 기능을 사용하면 해당 스크립트 배포 서버로 네트워크 요청이 발생합니다.

## 개인정보와 외부 연결

기본 분석, ZIP 해제, 검색, 보고서 생성은 브라우저 안에서 처리됩니다. 기본 상태에서는 가져온 코드를 이 프로젝트의 서버로 업로드하거나 브라우저 저장소에 보관하지 않으며, 페이지를 닫으면 원본 코드가 사라집니다.

설정에서 **분석 결과 기억하기**를 직접 켜면 메타데이터·기능 신호·판단 결과만 IndexedDB에 저장합니다. 원본 소스와 상담 대화는 이때도 저장하지 않습니다. GitHub Pages의 프로젝트들은 같은 계정 아래에서 브라우저 저장 공간을 공유할 수 있으므로, 공용 PC나 민감한 사내용 스크립트에서는 이 선택을 끈 채 사용하세요.

기억한 결과를 다시 연 뒤 개별 파일을 추가·교체하면, 저장하지 않은 원본과 새 파일의 문자열 전체를 대조할 수 없습니다. 이 경우 완전 중복 삭제 안내를 보수적으로 줄일 수 있으므로, 정확한 재검증이 필요하면 최신 백업 ZIP 전체를 다시 불러오세요.

외부 요청은 다음 기능을 사용자가 직접 켜거나 누른 경우에만 발생합니다.

- **최신 버전 확인:** 각 스크립트의 업데이트 주소로 메타데이터 요청
- **Gemini 상담:** 사용자의 질문과 구조화된 분석 요약을 Google Gemini API로 전송

Gemini 상담은 전체 소스 코드를 보내지 않으며, API 키는 저장하지 않고 현재 페이지 메모리에만 둡니다. 새로고침하면 다시 입력해야 합니다. 민감한 사내용 스크립트는 외부 기능을 켜기 전에 각 서비스 정책을 확인하세요.

## 알아둘 한계

이 도구는 **정적 분석 보조 도구**이지 악성코드 검사기나 실행 결과의 증명기가 아닙니다.

- 실행 중에 문자열로 만들어지는 선택자·주소·저장 키는 놓칠 수 있습니다.
- 같은 요소를 건드려도 서로 협력하도록 작성된 스크립트일 수 있습니다.
- 서로 다른 요소처럼 보여도 실행 순서나 사이트 상태 때문에 충돌할 수 있습니다.
- `직접 확인`은 오류가 있다는 뜻이 아니라, 자동으로 삭제 결정을 내리기에는 근거가 부족하다는 뜻입니다.

따라서 완전히 같은 원본이 아닌 파일은 자동 삭제 대상으로 취급하지 않습니다.

## 로컬 실행

빌드된 `app.bundle.js`가 있으면 정적 서버만으로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 파일로 직접 열 수도 있지만, 로컬 서버가 GitHub Pages와 더 비슷하게 동작합니다.

## 개발 및 배포

Node.js가 설치된 환경에서:

```bash
npm test
npm run build
npm run check
```

`npm run build`는 아래 순서로 읽어 실제 배포 파일 `app.bundle.js`를 만듭니다.

1. `vendor/jszip.min.js`
2. `analysis-core.js`
3. `app.js`

`app.bundle.js`는 생성물입니다. 직접 고치지 말고 원본 파일을 수정한 뒤 다시 빌드하세요. GitHub Pages에는 `index.html`, `styles.css`, `tampermonkey-logo.svg`, `app.bundle.js`와 라이선스·로고 출처 파일을 함께 배포합니다. 예전 `icon.svg`는 복원용으로 남아 있습니다.

## 파일 구조

- `analysis-core.js` — 메타데이터, 버전, 기능 지문, 충돌 후보를 판정하는 독립 분석 엔진
- `app.js` — 가져오기, 저장, 화면 표시, 보고서, 원격 확인, 상담 기능
- `index.html` — 화면 구조
- `styles.css` — 반응형 디자인과 색상
- `tampermonkey-logo.svg` — 상단 및 브라우저 탭에 표시되는 Tampermonkey 로고
- `TAMPERMONKEY-LOGO-NOTICE.md` — 로고 출처·별도 라이선스·비공식 관계 안내
- `app.bundle.js` — GitHub Pages가 실제로 불러오는 배포 번들
- `vendor/jszip.min.js` — ZIP 해제 라이브러리
- `tests/analysis-core.test.js` — 분석 엔진 회귀 테스트
- `examples/` — 안전한 예제 유저스크립트
