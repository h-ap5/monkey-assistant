# 몽키 어시스턴트 v0.4.0

Tampermonkey 백업 ZIP과 `.user.js` 파일을 브라우저에서 분석하는 GitHub Pages용 웹사이트입니다.

## v0.4.0 변경 사항

- 개인 API 키를 이용한 AI 상담 추가
  - OpenAI API
  - Gemini API
  - Claude API
  - OpenAI 호환 API 주소
- API를 쓰지 않는 기존 로컬 상담 유지
- API 키는 기본적으로 현재 탭의 세션에만 보관
- 사용자가 `이 브라우저에 API 키 기억`을 켠 경우에만 IndexedDB에 저장
- 관련 코드 일부를 AI에 전달할지 사용자가 직접 선택
- API 연결 테스트와 오류 안내 추가
- API 오류나 시간 초과 시 로컬 상담으로 자동 대체
- 상담 응답을 제목, 문단, 목록, 코드 블록으로 나누어 표시
- 상담창 폭과 글자 크기, 줄 간격 개선
- 기본 말투를 가벼운 고양이체로 변경

## API 사용 시 주의

이 사이트 자체는 API 키를 수집하거나 별도 서버로 전송하지 않습니다. AI 상담을 켜면 브라우저가 선택한 API 업체에 직접 요청합니다.

- API 사용료와 할당량은 각 사용자의 계정에 적용됩니다.
- 공용 PC에서는 `API 키 기억`을 켜지 않는 편이 안전합니다.
- `관련 코드 일부도 AI에 전달`을 켜면 질문과 관련된 유저스크립트 코드 일부가 API 업체로 전송됩니다.
- 키를 입력하지 않아도 로컬 중복·버전·충돌 분석과 로컬 상담은 계속 사용할 수 있습니다.

## 기존 GitHub 저장소 업데이트 방법

1. 이 폴더 안의 파일을 모두 선택합니다.
2. GitHub 저장소에서 `Add file` → `Upload files`를 누릅니다.
3. 파일들을 드래그해서 업로드합니다.
4. 같은 이름의 파일이 있으면 새 파일로 교체됩니다.
5. `Commit changes`를 누릅니다.
6. 배포 후 사이트에서 `Ctrl + Shift + R`로 강력 새로고침합니다.

중요한 파일은 다음 세 개입니다.

- `index.html`
- `styles.css`
- `app.bundle.js`

ZIP 분석 라이브러리와 앱 코드는 `app.bundle.js`에 함께 들어 있습니다.

## 사용법

1. Tampermonkey 대시보드에서 ZIP 백업을 만듭니다.
2. ZIP을 압축 해제하지 않고 몽키 어시스턴트의 업로드 영역에 놓습니다.
3. 분석 결과를 확인합니다.
4. 우측 하단 `어시스턴트` 버튼을 누릅니다.
5. 톱니바퀴에서 로컬 상담 또는 API 업체를 선택하고, 필요하면 개인 키를 입력합니다.

## 기본 모델

모델 ID는 설정창에서 직접 바꿀 수 있습니다.

- OpenAI: `gpt-5-mini`
- Gemini: `gemini-3.5-flash`
- Claude: `claude-sonnet-5`

모델이 계정에서 제공되지 않거나 이름이 바뀐 경우 해당 업체의 콘솔에 표시되는 모델 ID로 수정하세요.
